# Порты инфраструктуры MiniSSP

Все порты — отраслевые стандарты. Левый порт (host) можно менять при конфликте, 
правый (container) — нельзя.

| Сервис | Host | Container | Протокол |
|---|---|---|---|
| PostgreSQL | 5432 | 5432 | TCP |
| Redis | 6379 | 6379 | TCP |
| Kafka | 9092 | 9092 | TCP |
| ClickHouse HTTP | 8123 | 8123 | HTTP |
| ClickHouse native | 9000 | 9000 | TCP |
| Prometheus | 9090 | 9090 | HTTP |
| Grafana | 3000 | 3000 | HTTP |

## Почему именно эти числа

- **5432** — исторический порт Postgres.
- **6379** — MERZ на телефонной клавиатуре (фамилия создателя Redis).
- **9092** — стандарт Kafka, закрепился с первых версий.
- **8123 / 9000** — два протокола ClickHouse: HTTP и native.
- **9090** — дефолт Prometheus.
- **3000** — дефолт Grafana.

## Запомнить

- `${VAR}` в compose подставляется из `.env`.
- Формат `"host:container"` в `ports`.
- Если порт занят — меняем только левое число.
