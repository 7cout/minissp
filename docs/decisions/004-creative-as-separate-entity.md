# 004. Creative как отдельная сущность

- **Статус:** Принято
- **Дата:** 2026-09-25

## Контекст

Креатив был полями в Campaign. Но креатив должен подходить слоту 
по размеру и может быть разного типа — картинка, видео, HTML.

## Решение

Выделяю Creative в отдельную сущность. Чтобы не хранить все в Campaign

    ID, CampaignID, Type, Width, Height, URL, ClickURL
