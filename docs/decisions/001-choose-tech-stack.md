# 001. Стек и способ запуска

- **Статус:** Принято
- **Дата:** 2026-09-22

## Контекст

Делаю pet-проект — учебную SSP-платформу. Цель: перейти из ABAP в backend на Go, 
подготовиться к вакансии Junior Golang Engineer в T2 AdTech (Yabbi, SSP).

Стек вакансии: Go, gRPC, PostgreSQL, Redis, Kafka, ClickHouse, 
Kubernetes, Docker, Prometheus, Grafana.

## Решение

Беру весь стек из вакансии. Запускаю всё через Docker Compose. 
Kubernetes - в самом конце, если останется время и силы.

## Почему

- Хочу быть в контексте вакансии. Если позовут 
  на собеседование — надо знать весь стек, а не только Go.
- K8s попробую добавить в конце, когда все заработает

## Что отклонил

- K8s с самого начала — буду дольше разбираться в инфраструктуре, а не самом Go
- Минимальный стек (Go + Postgres) - быстрее, но для вакансии будет мало.

## Заметки

- Redis и ClickHouse пока под вопросом - может, для pet-проекта хватит 
  Postgres. Решу по ходу
