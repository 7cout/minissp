# Taskfile, линтеры и форматтеры

## Зачем это всё

Чтобы у всех на проекте был одинаковый стиль кода и 
одинаковые версии инструментов.

## Taskfile

**Что это:** замена Makefile, написан на Go. Позволяет описывать команды 
проекта в YAML и запускать их короткими именами.

**Где лежит:** `Taskfile.yml` в корне проекта.

**Установка:** `winget install Task.Task`

**Основные команды:**

    task              # список задач
    task --list       # то же самое
    task install      # установить инструменты
    task format       # отформатировать код
    task lint         # запустить линтер
    task test         # запустить тесты с -race
    task all          # полный цикл: check:go → format → lint → test

**Ключевые понятия:**

- `vars` — переменные (версии инструментов, пути).
- `deps` — зависимости задачи, выполняются **до** `cmds`.
- `cmds` — команды задачи.
- `status` — проверка «уже сделано?». Если да — `cmds` пропускаются.
- `task: имя` — вызов другой задачи из `cmds`.
- `silent: true` — не показывать команду в выводе.

**Где хранятся бинарники:** в `.bin/` в корне проекта. 
В `.gitignore`, у каждого разработчика свои.

**Как работает установка:**

    task install

- `install:mkdir` — создаёт `.bin/`, если нет.
- `install:gci` — ставит gci через `go install` в `.bin/`, если нет.
- `install:gofumpt` — ставит gofumpt.
- `install:golangci-lint` — ставит golangci-lint.

Повторный запуск ничего не делает — `status` проверяет, что уже есть.

## gci

**Что это:** форматтер импортов. Группирует и сортирует их по секциям.

**Установка:** через `task install`.

**Использование:**

    .bin/gci write -s standard -s default -s "prefix(github.com/7cout/minissp)" .

**Что делает:**

- `standard` — стандартная библиотека.
- `default` — сторонние пакеты.
- `prefix(...)` — пакеты твоего модуля (отдельной группой внизу).

**Результат:** импорты сгруппированы в три блока с пустыми строками между ними.

## gofumpt

**Что это:** более строгий форматтер, чем стандартный `gofmt`. 
Написан автором Go-инструментов mvdan.

**Установка:** через `task install`.

**Использование:**

    .bin/gofumpt -extra -w .

**Что делает:**

- `-extra` — дополнительные правила форматирования.
- `-w` — записать изменения в файлы.
- `.` — обойти текущую папку рекурсивно.

**Чем отличается от gofmt:** убирает лишние пустые строки, 
нормализует отступы в блоках, требует пустую строку между `if` и телом 
(если объявление выше). Строже — код чище.

## golangci-lint

**Что это:** мета-линтер. Запускает сразу десятки проверок за один проход.

**Установка:** через `task install` (в `.bin/`).

**Использование:**

    .bin/golangci-lint run ./... --config=.golangci.yml

**Конфиг:** `.golangci.yml` в корне проекта. В нём указано, 
какие линтеры включены, какие настройки, какие исключения.

**Что проверяет (часть):**

- `errcheck` — необработанные ошибки.
- `govet` — встроенный анализатор Go.
- `staticcheck` — глубокий статический анализ.
- `unused` — неиспользуемый код.
- `gocyclo` — цикломатическая сложность.
- `revive` — стиль кода.
- `gci`, `gofumpt` — форматирование.

## Как всё связано

    Taskfile.yml          ← описывает команды
    .golangci.yml         ← настройки линтера
    .bin/                 ← локальные бинарники (в .gitignore)

    task install          → ставит инструменты в .bin/
    task format           → запускает gofumpt + gci
    task lint             → запускает golangci-lint
    task all              → всё вместе

## Полезное

**Проверить, что делает задача:**

    task --dry install    # покажет команды без выполнения

**Если инструмент обновился:**

    rm .bin/gci           # удалить старый
    task install          # поставить новый

**Если поменяли версию в Taskfile:**

    rm -rf .bin && task install
