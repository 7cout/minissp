# MiniSSP

Учебная SSP-платформа для рекламных аукционов в реальном времени
со встроенным DSP-эмулятором.

## О проекте

Pet-проект на Go. Показывает полный цикл RTB:
от запроса площадки до списания денег с рекламодателя.

**Три сервиса:**
- **SSP** — принимает запросы на показ, проводит аукцион, ведёт балансы
  издателя и платформы.
- **DSP** — решает, участвовать ли в аукционе, управляет бюджетом
  рекламодателя, резервирует и списывает деньги.
- **Publisher** — эмулятор площадки, генерирует запросы на показ
  и подтверждает, что баннер был показан.

**Что демонстрирует:**
- gRPC-взаимодействие между сервисами.
- Аукцион second-price с таймаутами и параллельным опросом биддеров.
- Резервирование и списание бюджета с защитой от race conditions.
- Работу с PostgreSQL: пул соединений, миграции, атомарные UPDATE,
  схемы `ssp` и `dsp` для разделения доменов.
- Транзакции: `TransactionManager` для атомарного Commit+Spend в DSP.
- Два режима хранения: `STORAGE=memory|postgres`.
- Поток денег: advertiser → DSP → SSP → publisher + комиссия платформы.
