# MiniSSP

Учебная модель SSP-платформы для рекламных аукционов в реальном времени.

## О проекте

Pet-проект на Go. Цель — практика со стеком AdTech: gRPC, PostgreSQL, Redis,
Kafka, ClickHouse, Docker, Kubernetes, Prometheus, Grafana.

## Стек

- Go, gRPC
- PostgreSQL, Redis, ClickHouse
- Kafka
- Docker, Kubernetes
- Prometheus, Grafana
